第二次作业

一、太阳系元素丰度特征（论述）

太阳系元素丰度以“每10⁶个Si原子对应的原子数”为单位（GERM，1998），核心特征可总结为7点：

  1. 偶数原子序数优势：偶数原子序数元素的丰度高于相邻奇数原子序数元素（如O8＞N7、Si14＞Al13）。
  2. 轻元素绝对主导：H和He是丰度最高的元素，二者占太阳系总原子数的98%以上，远高于其他元素。
  3. 轻元素亏损现象：Li、Be、B丰度过低，属于“亏损元素”（如Li丰度仅57.1，Be仅0.73，远低于相邻的H、He、C）。
  4. Fe的过剩峰：Fe是丰度最高的重元素，形成明显的“峰”。
  5. 丰度随原子序数递减：Z＜45的元素，丰度随Z增大呈指数快速降低；Z＞45的元素，丰度曲线平缓下降，变化幅度小。
  6. 4倍质量数优势：质量数A为4的倍数的元素（如A=4的He、A=16的O、A=28的Si、A=40的Ca）丰度显著较高，这与恒星核合成中α粒子（⁴He核）参与的反应有关。
  7. 特定中子数核素过剩：当中子数N=50、82、126时，元素丰度曲线呈现“双峰”（如A=80/90、130/138、194/208的核素），这些核素结构更稳定。

最富集的元素

根据元素丰度推荐值（单位：原子数/10⁶个Si原子），太阳系最富集的元素为：

  • H：丰度2.79×10¹⁰，是太阳系中原子数最多的元素，占太阳质量的73.46%。
  • He：丰度2.72×10⁹，是第二富集元素，占太阳质量的24.85%。
  • C与O紧随其后，是轻元素中除H、He外最主要的组成。

最富集的元素：H、He、C、N、O

二、陨石研究对地球形成、组成及演化的意义

  1. 它是认识宇宙天体、行星的成分、性质及其演化的最易获取、数量最大的地外物质；
  2. 也是认识地球的组成、内部构造和起源的主要资料来源；
  3. 陨石中的60多种有机化合物是非生物合成的“前生物物质”，对探索生命前期的化学演化开拓了新的途径；
  4. 可作为某些元素和同位素的标准样品（稀土元素，铅、硫同位素）；
  5. 解析地球演化中的重大事件。

三、陨石的主要类别及特征

石陨石（又包括球粒陨石、无球粒陨石）、石铁陨石、铁陨石。

（1）球粒陨石

含有球体，具球粒构造，球粒由橄榄石和斜方辉石组成，基质为镍铁、陨硫铁、斜长石等。

（2）无球粒陨石

不含球粒，比球粒陨石结晶粗，在成分和结构方面，许多无球粒陨石与地球上的火成岩相似，因此它们可能由硅酸盐熔体结晶而成。

  • 原始无球粒陨石：富硅酸盐；
  • 分异无球粒陨石：成分复杂。
    • 贫钙：5%=＜CaO＜=30%，主要矿物为顽火辉石、紫苏辉石、橄榄石等；
    • 富钙：含单斜辉石或斜长石，其中钙长辉长无球粒陨石和古铜钙长无球粒陨石分布最广，属于富钙群。

（3）铁陨石

主要Fe-Ni金属及少量铁、硫磷的化合物，按Ni含量划分：

  • 方陨铁组：Ni在4~6%；
  • 八面体式陨铁组：Ni在6~14%；
  • 镍铁陨石组：Ni＞12~14%。

（4）石-铁陨石

硅酸盐相/Fe-Ni金属相=80-50%，大致由等体积硅酸盐相和铁镍相组成，根据两相比例分为橄榄陨铁和中陨铁两类。

  • 橄榄—陨铁；
  • 中陨铁；
  • 其他（古英铁镍陨石）。

第四次作业

一、自然体系和自然过程产物的特征

（一）自然体系特征

  1. 多组分的复杂体系
    自然作用体系中大量化学组分共存，浓度相差悬殊（O占47%，Rn为6×10⁻¹⁶）。任一地质作用都可看成是由90种元素和354种核素参加的体系。元素以其各自丰度决定的量比参加化学反应，这与实验室中以高纯试剂的有限组分体系按理论量比设计的化学反应有很大区别。

  2. 温度、压力等条件的变化幅度与人为制备的条件相比有限
    地壳和上地幔温度变化幅度为-801800℃，压力由0.0n10¹⁰Pa（十万大气压）。

  3. 开放体系
    具多变度单向发展演化特征。体系与环境之间存在充分物质和能量交换，因外来成分加入或内部组分排出不断改变系统内作用性质和条件。

  4. 自发进行的不可逆过程
    反应进行的方向、速率、限度受能量效应制约。由于作用能源来自地球本身，因此地球热量的空间分布控制着地球化学过程进行的规模和强度。同时由于自然体系为多相多组分复杂体系，化学反应还受动力学因素制约，作用过程具有不彻底性。

（二）自然过程产物特征

  • 自然稳定相（矿物）及各种流体相的总数有限；
  • 自然温度相—矿物都不是纯的化合物；
  • 元素成组分类形成自然组合；
  • 与各种阴离子结合的阳离子组成特征各异的共生元素组合；
  • 在地壳物理化学条件下，相似的物质组成和类似的作用过程会使自然作用产物类型重复出现，在一定程度上达到平衡。

二、自然体系中元素的赋存形式

（1）元素在固相中的存在形式

  • 独立矿物：是矿物的主要元素，并且在矿物晶格中占据一定位置。能用肉眼或能在显微镜下进行矿物学研究，粒径大于0.001mm。
  • 类质同象混入物：元素以离子分散状态参加到寄生矿物的晶格中，占据一定的晶格位置，含量变化不定。也称为结构混入物。机械和化学方法都无法使其分离。
  • 超显微非结构混入物（包裹体）：以显微矿物状态存在于矿物晶体内错位构造的间隙或其他空隙内。不占据晶格位置，又不形成可以进行矿物学研究的颗粒（粒径小于0.001mm）。
  • 吸附：以离子形式吸附于胶体、矿物颗粒表面或解理面上。结合力弱，易被交换和分离。
  • 与有机质结合：加入到有机物质中（生物摄取）或与有机质络合。

（2）元素在水流体相中的存在形式

  • 离子：几乎所有的元素均可以以离子的形式出现。
  • 分子：水分子、气体分子、有机质分子。
  • 胶体：胶体是物质的一种特殊分散状态，其特殊性是当质点粒径介于10⁻³~10⁻⁶mm时，它表现出不同于宏观颗粒许多物理化学性质。由于胶体质点表面积大，因而具有巨大的表面能，能够吸附大量带电粒子，这对元素的迁移有重要意义。

三、元素在颗粒物质中的存在形式和环境中的分类

元素在颗粒物质中的存在形式和环境意义不同，可以划分为：

  1. 碎屑相（结合态）：与硅酸盐矿物相结合，元素在环境变化过程中相对不易活动，含量基本保持固定。
  2. 非碎屑相（结合态）：与非晶质相结合，在环境变化中容易迁移，浓度因溶解—颗粒转换而改变（随污染增加而增加）。

四、元素在水溶液中的存在形式及主要控制因素

元素在水流体相中的存在形式：

  • 离子：几乎所有的元素均可以以离子的形式出现。
  • 分子：水分子、气体分子、有机质分子。
  • 胶体：胶体是物质的一种特殊分散状态，其特殊性是当质点粒径介于10⁻³~10⁻⁶mm时，它表现出不同于宏观颗粒许多物理化学性质。由于胶体质点表面积大，因而具有巨大的表面能，能够吸附大量带电粒子，这对元素的迁移有重要意义。

影响因素：

  • 离子电位决定了离子吸引价电子的能力。
  • 由于胶体质点表面积大，因而具有巨大的表面能，能够吸附大量带电粒子，这对元素的迁移有重要意义。
  • 水的偶极性质和高介电常数决定了对于离子键化合物（NaCl），通常形成一些简单离子。对于共价化合物，解离程度迅速减小。水溶液中分子和离子共存，分子可能更为主要。

五、元素的地球化学分类及其依据

Goldschmidt/戈尔德施密特元素地球化学分类

  1. 亲石元素
  2. 亲铜元素
  3. 亲铁元素
  4. 亲气元素
  5. 亲生物元素

亲石元素

典型的有K、Na、Ca、Mg、Si等，它们是主要造岩矿物的成分，富集于石陨石和岩石圈中。

  • 离子最外层电子具有8（2）电子稳定结构；
  • 与氧的亲和力强，氧化物的生成热高于FeO；
  • 电负性较小，易于形成高价离子键；
  • 易熔于硅酸盐熔体，集中于石陨石和岩石圈。

亲铜元素

亦称亲硫元素。典型的有Cu、Zn、Pb、Hg、Ag等，它们在陨石中富集于硫化物相内，在地壳中常呈硫化物产于硫化物矿床中。

  • 离子具有18或18+2铜型外层电子结构；
  • 与硫的亲和力强，氧化物的生成热小于FeO；
  • 中等电负性和电离能，形成共价键；
  • 与硫亲和性强，易熔于硫化铁熔体，集中于陨石的硫化物相和硫化物-氧化物过渡圈，常常形成硫化物、硒化物或碲化物。

亲铁元素

典型的有Ni、Co、Pt族和Au，它们集中于铁陨石和地球的铁镍核心中。

  • 原子最外层电子具有8-18电子过渡型结构；
  • 金属键，形成纯物质或合金；
  • 与氧和硫的亲和力均弱，氧化物和硫化物的生成热都不高（与亲石元素相比）；
  • 较高的电负性和第一电离能；
  • 密度：位于原子容积曲线的最低位置；
  • 呈自然金属存在，集中于铁陨石和地核。

亲气元素

包括惰性气体元素和易于形成气体分子N₂、O₂、CO₂、H₂O等，富集于大气圈中。

  • 原子最外层电子具有8电子稳定结构；
  • 最弱的键：分子键、原子键；
  • 原子容积最大，密度最小；
  • 具有挥发性或倾向形成易挥发化合物；
  • 集中于大气圈。

亲生物元素

典型的元素有C、N、O、H、P、B、Na、Si等，富集于有生命的动植物体内，主要包括除惰性气体以外的亲气元素及少量亲石元素。

分类依据

  1. 外层电子结构（化学键键性）；
  2. 原子容积；
  3. 对不同元素的亲和力。

第五次作业

一、元素自身的性质主要包括哪些方面？

① 原子的外层电子构型

核外电子处于不同的能量状态，相同能量的电子在空间互相组合，即为电子构型。电子构型和能量状态由四个量子数确定：n（主量子数）、l（角量子数）、m（磁量子数）、ms（电子自旋）。

  • 主量子数n：规定电子出现最大几率区域离核的远近和电子能级的高低。它决定层数，自核向外依次命名为K、L、M、N、O、P、Q等，分别与1、2、3、4、5、6、7层相对应。
  • 角量子数l：反映轨道形状，受n控制，为0、1、2、……、n-1。在同一层内l值不同的电子，彼此又组合成亚层，以s、p、d、f表示，分别与0、1、2、3……n-1相当。
  • 磁量子数m：反映轨道的方向性，m=-l…0…l。m有n个值，该亚层就有n个轨道。
  • 自旋量子数ms：电子自旋方向ms=-1/2或1/2。

② 原子的大小和离子半径

离子具有一定大小，离子半径指的是离子晶体中正负离子中心之间的距离等于正负离子半径之和，金属原子半径是两个相邻原子中心距离的一半。原子和离子的大小分为离子半径、共价半径、金属半径、分子半径等，构成一个复杂的半径体系。

原子的大小并不是一成不变的常数，它随化学键性、原子价态、配位模型以及环境的温度压力等条件而改变。同一元素阳离子的离子半径小于原子半径，阴离子相反，因此，同一元素阴离子的半径比阳离子大得多。原子（或离子）与其他原子（或离子）键合时键的长度也就是电子云的作用范围，不同配位和化合物价态给出的离子半径体系在离子键矿物中取得了较理想的效果。

元素半径变化的总体规律：

  1. 同一族元素向下原子半径增大；
  2. 同一周期内随原子序数增加原子半径逐渐降低；
  3. 从左上方到右下方的对角线方向，原子半径相近或相等；
  4. 镧系收缩，即镧系元素的离子半径随原子序数增加而减小。

③ 电负性

最早提出电负性概念的是鲍林，他认为组成化学键的两原子的电负性差值与所成键的离解能之间存在一定的关系，将电负性定义为X=I+E（I是电离能，E电子亲和能）。

电负性是指元素的原子在分子中吸引电子能力的相对大小，取决于A-B键合能与A-A和B-B键合能平均值的差值。

F电负性最高（X=3.9），F是最强的氧化剂，具有最高电离能和电子亲和能，保持本身电子能力最强，还有很强的从其他原子夺取电子的能力，为强电负性元素，酸性也最强。Cs的电负性最低（X=0.7），Cs既不能夺取电子，电离能很低还容易失去电子，为强电正性元素，键性也最强。

周期表由左到右X值增大，与同一周期元素从碱到酸的变化一致，其他元素的化合性质都可以从两个极端情况得到认识。到第八族X=1.8-2.2，铂族元素为明显的化学惰性，电离能很高，属于电正性元素；周期表右半部从H、B、Si、As、Te到Po、At为一条X=1.8-2.1的对角线，是金属与非金属的分界线，这些元素同氧化合时与氧争夺电子的能力与氢相同，化学上表现为两性，构成元素酸碱性的分界线。

  • X＞2的元素与氧共用电子形成酸根配离子，显酸性；
  • X＜2的元素给出电子，呈简单碱性阳离子形式存在。

④ 原子和离子的其他性质

  1. 配位数：原子（金属晶体）或离子（离子晶体）周围紧邻的原子或异号离子数。离子晶体的配位数取决于相互结合离子的半径比率，离子型晶体中只有阴阳离子完全紧密接触时，晶体才是稳定的。
  2. 极化：在外电场作用下，原子或离子电子云的大小、形状发生变化的现象。
  3. 离子电位：是表征离子电场强度的参数。离子的电荷和大小综合作用决定离子在化学反应中吸引价电子的能力，离子电位（π）等于离子电荷与半径的比值，它决定了元素的存在形式和迁移能力。
  4. 晶格能：相互远离的离子结合生成离子晶体时释放的能量。离子所带的电荷越多，晶格能越大；离子的半径越小，晶格能越大。

二、元素半径变化总体呈现哪些规律？

  1. 同一族元素向下原子半径增大。
  2. 同一周期内随原子序数增加原子半径逐渐降低。
  3. 从左上方到右下方的对角线方向，原子半径相近或相等。
  4. 失去电子，离子半径降低；获得电子，离子半径增大。
  5. 在周期表中从左上方到右下方，通过阳离子所作的对角线方向，其离子半径相近或相等。
  6. 镧系收缩：镧系元素的离子半径，随原子序数增加而减小。

三、元素结合的化学键主要包括哪些类型？如何准确判断化学键的键性？

3.1 化学键类型

离子键、共价键、极性共价键、金属键。

  • 离子键：一个原子将其外层电子轨道上的一个或多个电子转移到另一个原子的外层电子轨道，从而使两者都达到惰性气体构型，就形成了离子键。电负性相差较大的离子易形成离子键化合物。
  • 共价键：电负性相差很小或没有差别的元素不能永久地将电子从一个原子转移到另一个原子，成键原子间通过共用电子的方式形成化学键，称为共价键。如果共用电子对不是由二个原子平均分担，而是由其中一个原子给出一对电子和另一个原子共用，称配位键。
  • 金属键：金属原子易于失去外层电子而成正离子，自由电子与正离子产生引力作用，将正离子胶合在一起，从而显得正离子间也成某种结合，这种结合称为金属键。具有金属键的金属具有高导电性和导热性。
  • 分子键：分子键是由分子和晶体中电荷的不对称分布造成。
  • 氢键：氢键是带正电荷的H⁺与带负电荷的离子之间的静电键。

3.2 判断标志

两个相互作用的原子，电负性相差越大，键的离子性越强，越易形成离子键；反之，电负性相差越小，越易形成共价键。

由于化学键类型主要取决于电子云的偏离和重叠程度，因此可以用相互结合原子间的电负性差异来判断化学键类型。

电负性X=I+E（I-电离能，E-电子亲和能）。

  • 周期表右上角X＞2.1（H、C、O、F、Cl、Br、I），强-中电负性元素，以阴离子为主，组内元素相互或同种原子间反应形成共价键化合物，如H₂O、CO₂、N₂、O₂等。
  • 与1.7＜X＜2.1的元素结合，形成共价键为主易溶于水的酸根：SO₄²⁻、CO₃²⁻、VO₄³⁻等，易在水溶液中迁移。
  • 当与之化合的阳离子ΔX值较大时形成难溶共价键化合物MoS₂、PbS等。当存在高浓度高电负性配合剂，如Cl⁻、F⁻、S²⁻等，才能形成复杂配离子迁移。
  • 与X＜1.4电正性元素结合形成以离子键为主或过渡型键，离子键化合物（ΔX＞2）大多易溶于水。当ΔX=1.5-2因混有不同比例共价键，形成难溶化合物，需要高浓度强电解质配合剂才能使之迁移。
  • X=1.8-2.2，弱电负性，形成金属键-共价键化合物，难溶。
