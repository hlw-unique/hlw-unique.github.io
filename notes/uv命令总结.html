uv命令总结

#py

[[python机器学习]]

一、项目初始化与结构

uv init # 在当前目录创建新的 Python 项目（生成 pyproject.toml）
uv init –app # 创建应用程序项目（默认）
uv init –lib # 创建库项目（生成 src/ 布局）
uv init –name # 指定项目名称

二、虚拟环境管理

uv venv # 创建 .venv 虚拟环境（当前目录）
uv venv <路径> # 指定环境创建位置
uv venv –python 3.12 # 指定 Python 版本创建环境
uv venv –seed # 创建环境时一并安装 pip/setuptools

uv python list # 列出所有可用的 Python 版本（已安装+可下载）
uv python install 3.12.5 # 安装指定 Python 版本（绕过系统包管理器）
uv python pin 3.12 # 锁定项目使用的 Python 版本（写入 .python-version）

三、依赖与包管理

uv add <包名> # 添加依赖并写入 pyproject.toml + 锁定 uv.lock
uv add –dev <包名> # 添加开发依赖
uv add –optional <包名> # 添加可选依赖组
uv add “requests>=2.28” # 指定版本约束
uv add -r requirements.txt # 从 requirements 文件批量添加

uv remove <包名> # 移除依赖并更新锁定文件

uv sync # 根据 pyproject.toml 同步安装所有依赖（创建或更新环境）
uv sync –no-dev # 不安装开发依赖
uv sync –extra <组名> # 安装指定可选依赖组
uv sync –all-extras # 安装所有可选依赖

四、运行与执行

uv run <脚本> # 在项目虚拟环境中运行 Python 脚本/命令
uv run python # 启动项目环境的 Python REPL
uv run –script <路径> # 运行指定脚本文件
uv run –with <包> # 临时附加额外包运行（不修改项目）

uv tool run <工具名> # 运行一次性工具（类似 npx），如 uv tool run ruff check .

五、依赖解析与锁定

uv lock # 生成/更新 uv.lock 锁定所有依赖的精确版本
uv lock –upgrade # 升级所有依赖到符合约束的最新版本
uv lock –upgrade-package <包> # 仅升级指定包

uv tree # 以树形展示当前项目依赖关系
uv tree –depth 2 # 限制显示层级
uv tree –outdated # 高亮显示有更新的包

六、Python 包发布（PyPI）

uv build # 构建分发包（源码包 .tar.gz 和 wheel .whl）
uv build –sdist # 仅构建源码包
uv build –wheel # 仅构建 wheel

uv publish # 发布当前项目到 PyPI（需先 build）
uv publish –token # 使用 API token
uv publish –publish-url # 发布到私有仓库（如 GitLab）

七、工具与脚本隔离（类似 pipx）

uv tool install <工具名> # 安装全局命令行工具（如 ruff, black）
uv tool install ruff –python 3.12
uv tool uninstall <工具名>
uv tool list # 列出已安装工具
uv tool run <工具名> # 运行工具但不永久安装（临时执行）

uv script <文件.py> # 直接运行单一 Python 文件，自动解析其依赖（PEP 723）
uv script –python 3.11 <文件> # 指定 Python 版本运行脚本

八、兼容与迁移

uv pip install <包> # 兼容 pip 风格安装（但仍使用 uv 的 resolver）
uv pip list # 显示当前环境的包列表
uv pip freeze # 输出 requirements 格式
uv pip compile requirements.in # 生成锁定的 requirements.txt（类似 pip-tools）
uv pip sync requirements.txt # 同步环境至 requirements 精确内容

uvx # 等同于 uv tool run（简写别名）

九、管理命令

uv cache clean # 清理所有下载的缓存（包文件、Python 版本）
uv cache clean <包名> # 清理特定包的缓存
uv cache dir # 显示缓存目录路径

uv self update # 更新 uv 自身到最新版本
uv self uninstall # 卸载 uv（删除自身二进制）

十、常用组合示例

  • 创建新项目并安装依赖
    uv init myproject && cd myproject
    uv add fastapi uvicorn
    uv add –dev pytest
    uv sync

  • 运行开发服务器
    uv run uvicorn main:app –reload

  • 运行测试
    uv run pytest

  • 升级所有依赖
    uv lock –upgrade && uv sync

  • 发布包
    uv build && uv publish

所有子命令均支持 --help 获取详细参数。
